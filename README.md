# IPDPS 2026 PhD Forum Poster

## Optimizing Deployment of Irregular Sparse Deep Learning Workloads through ILP-Based Scheduling for Low-Latency Inference

**Changxin Li Sanmukh Kuppannagari**  
Case Western Reserve University  


---

## Abstract

Sparse Vision Transformers introduce irregular attention patterns that are difficult to execute efficiently on GPUs. This work presents a tile-aware scheduling framework that represents sparse attention as adjacency matrices, applies structure-aware reordering, extracts dense computation blocks, and uses profiling-guided integer linear programming to select hardware-efficient tile configurations. The proposed method generates feasible execution plans for low-latency inference and improves performance over fixed-tile FlashAttention baselines.
